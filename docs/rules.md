# 规则与模拟约定

本项目实现公开概率及机制，不宣称复现游戏服务器未公开的随机数算法。
规则依据随卡池快照的 `evidence` 保存，历史版本不会套用新卡池的机制。

## 星级与干员选择

先决定星级，再决定该星级内的干员。基础比例从该历史池读取，当前支持的基础六星概率为 2%。
若抽取前已有 `n` 次连续未出六星：

```text
p6 = min(1, 0.02 + 0.02 * max(0, n - 49))
```

前 50 抽基础概率为 2%，第 51 抽 4%，最晚第 99 抽六星。出六星后计数清零。
模拟约定：提升六星概率后，非六星按原先各自概率的比例分配剩余概率。

UP 数据的 `percent` 是**每个干员占该星级的比例**：两个各 0.35 的 UP 共占该星级 70%。
非 UP 干员分配剩余概率，普通权重为 100，`weight=500` 表示相对普通干员五倍，不是五百倍。
名单完全为 UP 时对来源中截断的小数归一化，禁止生成来源名单以外的干员。

首次十抽五星以上保证只在本池前十抽内生效一次，提前获得五星或六星即完成。
模拟约定：第十抽仍未完成时，将不足五星的结果提升为五星，保留正常六星概率。

## 特殊机制

- **定向选调**：适用池连续 150 抽未获得目标后，下一名六星必为目标，仅一次。
  提前自然获得目标会重置连续计数，但不会消耗这次选调。
- **标准／中坚双 UP 选调**：适用池累计 150 次后的下一名六星为两位直接 UP 之一；
  累计 300 次后的下一名六星为第一阶段选调的另一位，各一次。
  第 150、300 抽本身不强制提升星级。
- **旧版联动目标保底**：前 120 抽内必得目标六星，仅一次；提前自然获得目标会完成该保证。
- **新版联动目标保底**：每连续 120 抽内必得目标，获得目标后重新计数。
- **联动五星防重复**：首次获得任一当期 UP 五星后，下一名五星必为另一名 UP 五星，仅一次。
  中间获得其他星级不会消耗该保证。
- **联动目标五星保底**：适用池前 50 抽未得到当期 UP 五星，则之后下一名五星必为当期 UP 五星。
  不会将第 50 抽直接改为五星。
- 保底优先于该星级内的普通随机选择。五星防重复与目标五星保证同时可用时，先执行防重复；
  因其同样获得 UP 五星，目标条件也自然满足。
- 一井不模拟额外赠送、契约兑换或免费券领取，只模拟连续 300 次实际抽取。

## 状态边界

标准池六星连续未出计数共享，中坚池使用另一计数，限定和联动使用各自池 ID。
首次十抽、目标连续未出、五星保证、选调阶段和累计次数均按用户及池 ID 保存。
数据版本更新不创建新的用户进度域，管理员重新选同 ID 保留进度。
一井的所有进度从零开始，仅在本次计算中存在。

各来源的原始表、规范化规则和排除原因均可以从覆盖报告追溯。
